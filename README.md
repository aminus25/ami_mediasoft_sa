# Практическое задание: Проектирование и работа с БД (Сервис туроператоров, бронирования отелей и покупки билетов)

## Описание
В рамках задания была спроектирована и реализована база данных для cервиса туроператоров на основе ER-диаграммы.
В качестве СУБД использована **PostgreSQL**.

Из полной ER-диаграммы выбран связанный фрагмент из 4 таблиц:
`users`, `tour`, `booking`, `booking_tour` (связь M:N между бронированием и туром).

> Таблица `User` из диаграммы названа `users`, так как `user` — зарезервированное слово в PostgreSQL.

## Структура репозитория
- `01_schema.sql` — скрипт создания таблиц (DDL).
- `02_data.sql` — скрипт заполнения таблиц тестовыми данными (DML).
- `03_queries.sql` — скрипты SELECT-запросов по заданию.


## Выполненные требования
В файле `03_queries.sql` реализованы:
1. Агрегатные функции (`SUM`, `COUNT`, `AVG`) — запросы 1, 2, 3, 5, 6.
2. JOIN между 3 таблицами (запрос 2).
3. Оператор `GROUP BY` (с `HAVING`) — запросы 2, 3, 5, 6.
4. Вложенный запрос (Subquery) — запросы 3, 4.
5. Условный оператор (`CASE`) — запросы 5, 6.
